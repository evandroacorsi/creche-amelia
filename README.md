# Website Institucional - Creche Amélia Teixeira Lins

Este repositório contém o código-fonte do website institucional da **Creche Berçário Espírita "Amélia Teixeira Lins"**, localizada em Rancharia/SP.

O projeto tem como objetivo modernizar a presença digital da instituição, facilitando a comunicação com os pais, a transparência das atividades e a captação de doações e parcerias.

## 🚀 Sobre o Projeto

O site foi desenvolvido com foco em performance, acessibilidade e design responsivo. Ele inclui seções para:
- **História e Valores:** Apresentação institucional, missão e equipe.
- **Notícias e Eventos:** Sistema de listagem de novidades com carrossel de imagens e filtros por categoria.
- **Transparência:** Divulgação de parcerias (Prefeitura Municipal) e prestação de contas.
- **Doações:** Informações claras sobre como contribuir (PIX, materiais, voluntariado).
- **Contato:** Formulário direto e links para redes sociais/WhatsApp.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias modernas de desenvolvimento web:

- **[React](https://reactjs.org/):** Biblioteca principal para construção da interface.
- **[Vite](https://vitejs.dev/):** Build tool para desenvolvimento rápido e otimizado.
- **[TypeScript](https://www.typescriptlang.org/):** Superset do JavaScript para tipagem estática e segurança de código.
- **[Tailwind CSS](https://tailwindcss.com/):** Framework de utilitários para estilização ágil e consistente.
- **[shadcn/ui](https://ui.shadcn.com/):** Coleção de componentes de interface reutilizáveis e acessíveis.
- **[Lucide React](https://lucide.dev/):** Biblioteca de ícones leve e moderna.
- **[React Router](https://reactrouter.com/):** Gerenciamento de rotas e navegação SPA (Single Page Application).

## 📦 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (versão 18 ou superior recomendada)
- npm (geralmente instalado junto com o Node)

Siga os passos abaixo para executar o projeto em ambiente de desenvolvimento:

1. **Clone o repositório:**
   ```bash
   git clone <URL_DO_SEU_REPOSITORIO>
   cd nome-do-projeto

2. **Instale as dependências:**

   ```bash

3. **Inicie o servidor de desenvolvimento:**

   ```bash
